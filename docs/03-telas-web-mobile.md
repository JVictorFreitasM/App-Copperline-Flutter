# Telas — portal web e app mobile

## Portal web (uso geral)

| Tela | O que o usuário faz |
|---|---|
| Painel | Acompanha indicadores de vendas, funil de pedidos, ranking e alertas |
| Pedidos / Novo pedido / Detalhe / Histórico | Lista, cria, consulta e acompanha a evolução de status de um pedido |
| Clientes / Ficha do cliente | Lista clientes e vê ficha completa (financeiro, localização, histórico, resumo por IA) |
| Produtos / Detalhe do produto | Consulta catálogo, preço, estoque e manual técnico |
| Estoque | Consulta saldo disponível por produto |
| Tabelas de preço | Consulta tabelas e seus itens |
| Notas fiscais | Consulta notas emitidas e seu status |
| Busca | Busca unificada por cliente/produto/pedido |
| Aprovações | Fila de solicitações de desconto pendentes de aprovação do usuário logado |
| Rastreio da equipe | Visualização da localização/roteiro da equipe em campo (gestores) |
| Configurações | Abas: alçada de aprovação de desconto, orçamento e política de rastreio |

## Portal web (administração)

| Tela | O que o usuário faz |
|---|---|
| Sincronização / Logs | Acompanha e ajusta a sincronização com o ERP/BI, com histórico de execuções |
| Vendedores | Gerencia hierarquia de vendedores e coberturas temporárias |
| Visitas | Consulta visitas realizadas pela equipe |
| Documentos | Faz upload e gerencia documentos institucionais |
| Pagamento | Gerencia formas e condições de pagamento |
| Tipos de acondicionamento | Cadastra embalagens/unidades de produto |
| Relatório de pedidos | Consulta relatórios gerenciais de pedidos |
| Qualidade de dados | Verifica consistência dos dados sincronizados do ERP |
| Importar Swagger | Ferramenta técnica para importar definições de endpoints (uso interno de desenvolvimento) |

## App mobile (vendedor em campo)

| Tela | O que o usuário faz |
|---|---|
| Login / Verificação de sessão | Autentica via SSO corporativo |
| Configurar servidor | Define o ambiente/servidor usado pelo app |
| Início | Vê atalhos e resumo do dia |
| Clientes / Ficha do cliente | Consulta clientes (mesmo propósito da versão web, adaptado a campo) |
| Produtos / Detalhe do produto | Consulta catálogo, preço e estoque |
| Pedidos / Detalhe / Criar pedido | Lista, consulta e cria pedidos — inclusive offline |
| Resolver conflito | Resolve o caso em que uma ação feita offline não pôde ser aplicada ao sincronizar (ex: pedido alterado enquanto o vendedor estava sem internet) |
| Tabelas de preço | Consulta tabelas de preço |
| Estoque | Consulta saldo de estoque em campo |
| Busca | Busca unificada por cliente/produto/pedido |
| Aprovações | Aprova solicitações de desconto pelo celular |
| Roteiro | Visualiza roteiro/visitas do dia |
| Configurar rastreio | Configura/consente o compartilhamento de localização em campo |
| Configurar notificações | Define preferências de notificações push |
